# Shahab Sherafat

My personal academic website: [shahabsherafat.github.io](https://shahabsherafat.github.io/).

I study computer engineering at the University of Tehran. My research interests include AI safety, adversarial robustness, generative AI, and AI for medicine.

The site includes my research experience, publications, teaching, and CV.

## Editing

- Personal details and experience: [`_data/cv.yml`](_data/cv.yml)
- Homepage: [`_pages/about.html`](_pages/about.html)
- Online CV: [`_pages/cv.html`](_pages/cv.html)
- Downloadable CV: [`assets/pdf/CV-Shahab-Sherafat.pdf`](assets/pdf/CV-Shahab-Sherafat.pdf)
- Appearance and interactions: `assets/css/personal.css` and `assets/js/personal.js`

## Run locally

With Ruby, Bundler, Node.js, and npm installed:

```sh
bundle install
npm ci
bundle exec jekyll serve
```

Open [localhost:4000](http://localhost:4000/).

See the [site guide](docs/PERSONAL-SITE.md) for more editing and publishing details.

Built with [Jekyll](https://jekyllrb.com/) from the [al-folio](https://github.com/alshedivat/al-folio) starter and hosted on GitHub Pages.
